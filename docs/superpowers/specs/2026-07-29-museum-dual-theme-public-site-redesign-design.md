# 同学录“存忆馆”双主题公开站点重构设计规格

日期：2026-07-29
状态：已确认

## 1. 结论与范围

公开站点重构为“存忆馆”双主题体验：白天是可阅读的馆藏档案，夜晚是同一馆藏的低照度展厅。它采用 `C:/Users/Administrator/Downloads/alumni-book-redesign.html` 的日夜配色角色、展签式层级和档案语法，但不移植该演示稿的本地状态、模拟数据、`innerHTML` 路由或占位照片。

本规格取代此前设计中与本次决定冲突的部分：不再将暖纸主题视为唯一常规页面外观；日间与夜间均为正式主题。此前的 API、登录、会话、上传、私信、班级群聊、个人档案和打印功能不改变。

本次覆盖：公开站点主题令牌、主导航、序、花名录、班级空间、年度册、更多，以及与上述页面相连的相册、个人档案和信箱视觉规则。

## 2. 已确认的产品决策

### 2.1 主题与产品语言

- 日间和夜间是同一“存忆馆”的两种照明状态，不是两套品牌。
- 日间偏暖纸、墨棕、克制金色、印章红；夜间偏深绿黑、柔金、砖红印章、低饱和绿。
- 颜色只按语义角色使用：背景层、表面层、正文、辅助文字、导向强调、确认印章、状态绿和焦点环。
- 主题默认遵从系统色彩偏好，用户手动切换后持久化；既有静音偏好独立保留。

### 2.2 一级导航

桌面主目录与移动抽屉使用同一顺序：

| 标题 | 路由 | 说明 |
| --- | --- | --- |
| 序 | `/preface` | 现有前言，改为展厅序章 |
| 花名录 | `/roster` | 现有同学档案 |
| 班级空间 | `/class-space` | 群聊、精选影像、班级大事 |
| 年度册 | `/yearbook` | 可打印、可导出的装帧年鉴 |
| 更多 | `/more` | 保留更新目录定位，不虚构新功能 |

- 馆徽仍链接首页 `/`；首页继续承担入馆登录，不并入“序”。
- 相册 `/album` 保留独立页面和既有路由，不占用一级导航；从班级空间的“精选影像”及个人档案相关入口进入。
- 信箱、账号、主题、音效及条件化管理入口保持在导航工具区；移动端进入抽屉工具区。

## 3. 主题令牌与迁移规则

### 3.1 语义层

在 `packages/site-astro/src/styles/` 建立或归并以下语义令牌，组件只引用语义名，不直接依赖日夜颜色：

```css
--surface-canvas;
--surface-sunken;
--surface-raised;
--surface-paper;
--text-primary;
--text-secondary;
--text-muted;
--border-subtle;
--border-strong;
--accent;
--accent-strong;
--accent-soft;
--stamp;
--state-archive-green;
--focus-ring;
--shadow-surface;
```

日间映射以 `#F1E7CE / #FBF6E9 / #221A10 / #7C6C49 / #6E5322 / #A23B2A / #4A7159` 为基准；夜间映射以 `#0B120E / #161F19 / #EDE6D2 / #93A092 / #E7CE8C / #B24630 / #4C8267` 为基准。最终实现可微调对比度，但不得改变角色关系。

### 3.2 过渡方式

- 既有 `--color-paper-*`、`--bg-*`、`--text-*` 等令牌逐步别名到新语义层，先避免核心页面同时维护两套颜色逻辑。
- `MainLayout.astro` 的主题初始化、主题切换触发点和 `localStorage` 行为保留；只收敛主题值和被切换的令牌集。
- 全局环境层保持纯装饰、`pointer-events: none`；不得遮挡导航或扩大页面溢出范围。
- 日夜切换仅动画 `opacity` 与 `transform`。`prefers-reduced-motion: reduce` 时立即结束为目标主题。

### 3.3 可访问性与性能

- 正文、输入框、辅助信息、按钮和焦点环均达到 WCAG AA 对比度；日夜主题分别验证。
- 不使用全局自定义光标、常驻 `requestAnimationFrame` 视差循环、模拟图片色块或阻断性“入馆加载幕”。
- 现有音效仅在已有语义触发点继续使用：档案悬停/滑动、相册打开、抽屉收合和确认。保留延迟 AudioContext、静音、可见性暂停、双声部上限和减弱动效约束。

## 4. 页面级设计

### 4.1 首页 `/`

首页继续是未登录用户的入馆与账号登录入口。它保留现有访客通行证、首次登录改密和会话守卫，不展示完整的馆内主目录。首页可以采用存忆馆的日夜令牌和居中馆徽，但不复制“序”的统计登记簿，避免两个入口页面争夺同一叙事。

### 4.2 序 `/preface`

“序”采用居中轴对称的展厅序章，顺序固定为：

1. 馆徽/印章圆环、馆藏标签、主标题与副文案均在中轴上。
2. 真实“入馆登记簿”：在册同学数、班级影像数、共同篇章数。数据由已有同学、相册和时间轴/已审核内容读取；无数据时显示真实 `0` 或既有空状态，不伪造数字。
3. 仅两个主行动：`翻开花名录` 指向 `/roster`，`前往班级空间` 指向 `/class-space`。
4. 现有前言正文、致谢墙与相关留言保留，作为居中单栏的“馆长题记”。

不在本页增加年度册入口、第三个主行动或左右不对称的内容列。

### 4.3 花名录 `/roster`

花名录采用“中轴索引册”：

- 页面标题、说明、档案检索框、结果数量和分页均居中对齐。
- 桌面使用等宽三列的规则索引网格，移动端降为两列或一列，不出现横向滚动。
- 每张索引卡固定呈现头像、档案编号、姓名和真实档案状态；座右铭、标签等详细叙事只在个人页或明确展开状态显示。
- 保留 `RosterWall.vue` 的关键词检索、每页 12 条、空状态、分页稳定高度、身份转场、档案悬停音效、移动端光影授权和个人页返回状态。
- 规则索引网格不使用随机旋转与错位；指针/陀螺仪光影是可选增强，不影响网格尺寸或可读性。

### 4.4 班级空间 `/class-space`

班级空间改为“横向目录，纵向展陈”：

- 页面标题与说明居中。
- 标题下是无编号的三项横向展区导航：`班级群聊`、`精选影像`、`班级大事`。桌面端等宽居中铺开，当前项用细金线与表面色区分；移动端变为全宽纵向触控项。
- 内容区保持当前线上顺序并使用锚点：班级群聊 → 精选影像 → 班级大事。
- 班级群聊保留实时连接、历史加载、新消息提示、回复、反应、撤回、我的记录与输入器；它是第一个完整展区而非缩略卡。
- 精选影像保留当前相册轨道、上传/投稿能力和 `/album` 直达入口；使用真实封面媒体与题签。
- 班级大事保留时间轴、真实图片、详情及 `/timeline` 直达入口。
- 移除桌面端左侧固定编号竖条导航，不删除当前 `ClassSpaceSectionNav` 的锚点、活动追踪和移动端能力，而是将其重构为上述横向组件。

### 4.5 年度册 `/yearbook`

年度册的定位是“装帧年鉴”，不是实时数据仪表盘：

- 保留 `打印此纪念册 / 导出 PDF`，打印样式固定为高对比日间纸张，不随夜间主题打印成深色底。
- 页面按封面、班级寄语、青春数据报告、同窗名录、青春瞬间、时光足迹、精选留言的现有章节纵向展开。
- 封面与各章节居中，使用统一的年鉴页边、展签标签和细分隔线；真实数据报告仅是其中一章。
- 人气排行、访问量等真实数据不使用夸张视觉占据封面，也不添加没有来源的精确数字。

### 4.6 更多 `/more`

更多页只进行主题与版式迁移：保留“新的章节正在整理”的真实状态，用馆内更新目录的视觉表达。除非后续提供明确的功能、内容和入口，不添加虚构栏目或无效链接。

### 4.7 关联页面

- 相册 `/album`：保留真实照片、响应式变体、轻盒与无障碍文本；视觉采用档案夹、接触印相、题签和日期，不使用渐变色块冒充照片。
- 个人档案 `/student/[slug]`：使用档案编号、隐私字段的锁定提示、真实“留念”状态和同窗留言；不改变模板 iframe 的 sandbox、变量替换与标准页面互斥契约。
- 信箱 `/mailbox`：用“往来书信”视觉强化线程和群聊记录，但不改变会话令牌、未读数、私信或群聊行为。

## 5. 不变契约

- 不修改 Worker 数据模型、迁移、公开/私有 API 路由、会话令牌、速率限制和权限语义。
- 不改变 `MainLayout.astro` 的首次加载与客户端导航会话守卫。
- 不改变自托管同源 `/api` 规则，SSG 构建仍显式提供 `VITE_SSG_API_BASE`。
- 不读取或输出密钥、生产环境文件内容及用户敏感资料。
- 当前工作区中由其他任务修改的 `ClassSpaceAlbumRail.vue`、`SelfEditPanel.vue`、共享类型、Worker 路由与测试文件均不纳入本次视觉修改，实施时必须保留其行为并在冲突处先复核。

## 7. 验收标准

### 7.1 视觉与结构

- 日夜主题在首页、序、花名录、班级空间、年度册、更多中使用同一语义令牌，且正文/辅助文字/按钮/焦点状态可读。
- 主导航顺序准确为“序、花名录、班级空间、年度册、更多”；移动端顺序一致。
- 序的标题、登记簿、双按钮与馆长题记均为中轴对称或居中单栏；仅有两个主行动。
- 花名录为规则三列索引网格，不再出现随机静态角度。
- 班级空间无桌面左侧编号竖条；横向目录与纵向内容顺序准确为群聊、影像、大事。
- 年度册可在日/夜界面中阅读，并在打印/PDF 时生成正确的日间纸本版式。

### 7.2 功能与回归

- 未登录访客只能按既有规则访问首页；受保护的序、花名录、班级空间、年度册和更多维持重定向守卫。
- 花名录检索、分页、个人档案 view transition 和返回状态正常。
- 班级群聊的加载、发送、反应、撤回、我的记录、锚点导航、相册投稿和时间轴入口正常。
- 相册、个人模板、隐私字段、留念、信箱和打印功能保持既有行为。

### 7.3 验证层级

- 每个改动组件先运行对应 Vitest 静态测试；主题、导航或跨组件接口变更后运行 `pnpm --filter site-astro typecheck`。
- 导航、主题、真实交互、移动端布局或页面生命周期变化，补充并运行对应 Playwright 用例。
- SSG 产物变化时，使用显式且可信的 `VITE_SSG_API_BASE` 运行站点构建。
- 大范围视觉迁移合并前执行 `pnpm verify:all`；本规格阶段不部署、不变更线上数据。

## 8. 实施边界与顺序

实现计划将按以下依赖顺序拆分：

1. 主题语义令牌、日夜切换与全局可访问性回归。
2. 导航目录与工具区，确保路由/会话不变。
3. 序与花名录，验证中轴和索引布局。
4. 班级空间，保留现有纵向功能流并替换导航外观。
5. 年度册、更多及关联相册/个人档案/信箱的令牌收口。
6. 聚焦测试、桌面/移动视觉 QA、打印 QA 和全量验证。

任何阶段发现与当前未提交改动重叠时，先暂停该文件的视觉改动，比较契约与测试后再继续。

## 9. 自审

- 不含任何未决占位要求。
- 日夜主题、导航映射、序的双按钮、花名录索引、班级空间纵向顺序、年度册定位均有唯一结论，互不矛盾。
- 不新增后端、数据库、虚构内容或未经授权的生产动作。
- 范围集中于公开站点视觉系统与现有页面编排；功能契约只作为必须保留的边界，不引入独立业务子项目。
