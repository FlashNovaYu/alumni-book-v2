# 移动端沉浸光影设计说明

## 目标

在 HTTPS 正式域名上，为触屏设备提供用户主动开启的陀螺仪沉浸光影；它让全局星空背景和首页两处入口产生克制的随设备倾斜效果，并复用花名录现有的方形卡片光影。

## 交互与边界

- 首页与花名录均提供明确的“开启”操作；绝不在首次进入时请求传感器权限。
- iOS 的权限请求严格由按钮点击触发；Android 和其他支持设备直接开始监听。
- 在 HTTP、浏览器不支持或用户启用“减少动态效果”时，显示可理解的降级状态；花名录仍可通过触摸位置显示卡片光影。
- 陀螺仪只更新 CSS 自定义属性并经 `requestAnimationFrame` 平滑，不读取、存储或上传运动数据。
- 视觉幅度限制在背景约 16px、首页入口约 5px，避免眩晕、影响点击或产生内容位移。

## 实现结构

`useMouseTilt.ts` 继续作为唯一的方向事件与权限入口，并把平滑后的全局偏移写入根元素 CSS 变量。`MainLayout.astro` 消费变量移动星空图层；`MuseumHero.astro` 在移动端渲染授权入口、同步状态并让两个现有磁性入口消费同一组变量。花名录原有卡片继续使用同一运行时，因此无需新增传感器监听器。

## 验收标准

1. HTTPS 移动视口可见“开启沉浸光影”，按钮点击后状态切换为已开启或明确降级说明。
2. 方向事件改变时，根元素的背景和首页入口偏移变量更新；数值在设计上限内。
3. 关闭或不支持方向事件时，卡片触摸光影、页面导航、减少动态效果均保持既有行为。
4. `mobile-gyro-static.test.ts`、相关静态测试、站点类型检查通过；正式域名以移动视口无控制台错误。
