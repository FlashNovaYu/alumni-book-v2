# 参考稿级星空与档案索引卡重构设计说明

## 目标

让正式站点的全局背景与花名录回到参考视觉文件的核心体验：背景具有可感知但不干扰阅读的景深、缓慢漂浮和视差；同学卡片呈现为完整的方形档案索引卡，而非“圆头像加文字”的普通信息卡。

本次只重构背景层与花名录卡片层，不改变导航标题、路由、资料字段、分页、登录、上传或现有深浅主题的业务结构。

## 保护规则

- 保留现有深夜模式与纸张日间模式，以及它们的品牌色、文字内容和导航结构。
- 保留 `useMouseTilt.ts` 作为设备方向权限与卡片交互的唯一入口；不增加第二套方向事件监听器。
- 保留同学卡片的链接、资料页转场、懒加载图片、音效和无头像降级。
- 不复制参考文件中的模拟数据、路由实现或演示文本，只复刻视觉语法与交互层级。

## 背景：单一星空引擎

### 组成

`MainLayout.astro` 中现有的多套静态星点背景将收敛为一个全屏 Canvas 引擎和一个 CSS 雾光层。

1. **深景星层**：低亮度、小尺寸、最慢速度，营造远景。
2. **中景尘层**：少量暖金星尘，具有不同的漂移起点、时长、透明度与方向。
3. **近景闪层**：极少量带柔和 halo 的星点，仅在视窗边缘缓慢经过。
4. **雾光层**：两个低饱和大面积光团，分别取自现有金色与砖红/纸张墨色 token，以 28 至 36 秒的周期漂移和呼吸。
5. **景深响应**：桌面端以指针位置产生不超过 14px 的各层差异位移；移动端仅在用户授权后消费现有陀螺仪变量，最大位移不超过 16px；无权限时仍保留自主漂移。

### 渲染与性能

- Canvas 仅绘制装饰性粒子，内容不依赖 Canvas 才可读。
- 粒子布局由确定性种子生成，页面切换后不会随机跳变；根据 DPR 限制绘制分辨率，移动端降低粒子数。
- 循环只在页面可见、未启用 `prefers-reduced-motion` 时运行；不可见时暂停，减少动态效果时渲染静态首帧。
- 删除 `.page-shell` 和旧背景中重复的固定星点，避免双重亮点、叠层发灰及每页位置重合的问题。

### 主题映射

| 层级 | 夜间模式 | 日间模式 |
| --- | --- | --- |
| 底色 | 现有深色 token | 现有纸张 token |
| 星尘 | 米白与低饱和金色 | 褐墨与低饱和砖红 |
| 雾光 | 金色与砖红，低透明度 | 金色与印章红，进一步降低透明度 |
| 混合 | `screen` | `multiply` |

## 花名录：档案索引卡

### 构图

每张卡片保持 1:1 方形，但改为参考稿的档案结构：

1. 顶部左侧为装订孔，右上角为档案编号。
2. 中部为矩形主视觉照片，占卡片高度约 48%，使用真实头像/背景图片的现有响应式资源；无图时使用姓名首字母的同尺寸档案占位。
3. 主视觉下为一条细分隔线。
4. 下部依次显示姓名、最多两行座右铭和一枚主标签；状态文字仅在确有状态时以低权重显示。
5. 卡片圆角、描边与阴影采用当前主题 token，但降低“通用圆形头像卡”的辨识度。

### 布局

- 宽屏：四列等宽方卡，间距约 18px。
- 平板：两列。
- 手机：一列，保留正方形比例及 44px 以上触控目标。
- 不改变现有检索、分页、资料页 view transition 或数据排序。

### 互动

- 精细鼠标设备：每张卡片最大 `rotateX/rotateY` 为 5deg，悬停时抬升 4px；高光根据指针落点在照片和表面局部移动，不使用整卡泛白。
- 触摸设备：不使用 hover 假象；已有触摸光影与授权后的陀螺仪仅驱动局部高光。
- `prefers-reduced-motion`：禁用倾斜、漂移与高光过渡，卡片与背景保持清晰静态终态。

## 视觉验收标准

1. 桌面静置时仍能辨认出至少三种速度和亮度的背景景深，滚动或移动指针时背景层之间的位移不同。
2. 日间模式不是夜间模式的简单反色：星尘转为纸面墨点，雾光、描边和混合模式均与纸张层协调。
3. 花名录在宽屏显示四列方形档案索引卡，照片、装订孔、编号、分隔线、姓名与摘要构成稳定的垂直层级。
4. 卡片悬停可见局部跟随高光与小幅透视，且不会造成内容位移、横向溢出或影响点击。
5. 手机端授权陀螺仪后仅产生轻量背景/高光响应；拒绝权限、低性能设备和减少动态效果均有静态或触摸降级。
6. 通过相关 Vitest、站点类型检查、桌面与移动 Playwright 视觉/交互测试，并在 `https://aluminbook.icu` 验证无控制台错误、无混合内容。

## 明确不做

- 不引入 Three.js、WebGL、外部纹理文件或持续占用 CPU 的高密度粒子特效。
- 不修改 API、数据库 schema、同学资料数据或后台管理流程。
- 不改变现有导航顺序与用户确认的页面命名。
